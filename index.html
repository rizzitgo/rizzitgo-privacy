Privacy Policy

Last updated: August 13, 2026

This Privacy Policy explains how RizzitGO Bot ("we", "the bot") collects, uses, and protects information on Discord.

1. Data We Collect

RizzitGO Bot collects and stores the following data:

  • Discord user ID
  • Server (guild) ID where the bot is used
  • Parcel number submitted by users when entering the Milestone Lottery (via the !entry command)

Beyond the parcel number used for lottery entries, the bot does not store message content or personal data. Features such as shipping coupons, coupon restoration, and the Spin feature communicate with the official RizzitGO website API to process requests. Data exchanged with our own API (e.g., your Discord ID and coupon code) is used only to complete the request and is not stored beyond what is required to deliver the result (e.g., sending the redemption link via DM).

2. How We Use the Data

The stored parcel number is used exclusively to:

  • Track and verify lottery entries per user (parcel numbers, entry counts, and draw eligibility)
  • Enforce entry limits (e.g., maximum entries per user)

The following features are processed in real time through the RizzitGO website API and are not stored by the bot:

  • Delivering coupon redemption links via Direct Message
  • Restoring expired coupons when requested via the !restore command
  • Processing Spin feature requests

3. Data Storage

Data is stored securely and is not sold, rented, or shared with third parties for commercial purposes. Coupon, discount, and Spin features communicate with the RizzitGO website API (our own platform) to generate results and redemption links. No data is shared with unrelated external companies.

4. Data Retention

Parcel numbers submitted for lottery entries are retained until the relevant milestone draw is completed, after which they may be deleted or anonymized. You may request the deletion of your data at any time by contacting us at the email below.

5. Your Rights

You have the right to request access to, correction of, or deletion of your personal data (including submitted parcel numbers) at any time.

6. Contact

For questions about this Privacy Policy or your data, contact us at: support@rizzitgo.com, or reach out through our official RizzitGO Discord server support channels.

This policy may be updated periodically. We recommend checking it regularly.
